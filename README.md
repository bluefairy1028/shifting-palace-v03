# 移宫 Shifting Palace — V0.4

一款双人抽象策略游戏原型。玩家不能直接移动旅人，而是通过滑动机关方块，让承载旅人的载具依次抵达中央神殿，并从对面的出口离开。

## 在线试玩

https://bluefairy1028.github.io/shifting-palace-v03/

## 游戏模式

- 单人对战 AI：入门、标准、挑战三档难度
- 本地双人：两名玩家在同一台设备上轮流操作

## 基本目标

1. 从自己的起点出发。
2. 进入棋盘中央的唯一神殿。
3. 从对手一侧的出口离开棋盘。

每回合先滑动一个普通机关块；若载具仍无法移动，可进行一次救援滑动。随后移动载具。普通机关块不能进入神殿，旅人与载具始终绑定。

## 本地运行

直接打开 `index.html` 即可，或在当前目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。
